NOVA Lite

A lightweight, free, mobile-friendly productivity and coding workspace.

Features

Code Editor — Write and organize code.

HTML Preview — Preview HTML projects.

JavaScript Runner — Run JavaScript experiments.

Vira — An optional coding tutor.

Flashcards & Notes — Keep track of learning and ideas.

Coddy Shortcut — Quick access to Coddy.

Local Storage — Save projects on your device.

Getting Started

Open the NOVA Lite website.

Create or open a project.

Write your code.

Use Preview or Run where supported.

Installation on iPhone

Open NOVA Lite in Safari.

Tap the Share button.

Select Add to Home Screen.

Privacy

NOVA Lite is designed to keep project data on your device. Do not enter passwords, API keys, or other secrets into projects.

Cost

NOVA Lite is intended to be free to use. No paid subscription is required.

Project Status

NOVA Lite is under development. Some planned features may not be available yet.
